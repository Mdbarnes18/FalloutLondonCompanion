# Desktop clients

Windows and Linux are first-class Fallout London Companion targets.

Release artifacts:
- Windows installer
- Windows portable self-extracting EXE
- Linux AppImage
- Linux Flatpak
- Linux DEB
- Linux RPM

The desktop target uses Kotlin/JVM + Compose Multiplatform and follows the same five-tab ATTA-BOY information architecture as the mobile clients. Protocol-dependent actions remain capability-gated until verified from fresh Fallout: London captures.

The application icon is copied from the locked project AppIcon asset during CI. It must not be edited or regenerated as artwork.
