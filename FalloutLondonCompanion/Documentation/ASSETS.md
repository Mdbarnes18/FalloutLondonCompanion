# Assets

## User-Supplied ATTA-Boy References
The five supplied reference images are the primary visual reference set for the physical ATTA-Boy shell. They are distinct from the Fallout Wiki archive and should not be silently replaced with generic Pip-Boy references.

## Fallout: London
The supplied wiki archive identifies the custom ATTA-Boy and its Protect and Survive-inspired interface. Individual assets must still be evaluated for their specific redistribution terms.

Private Discord conversations, screenshots, usernames, and permission correspondence are not included in the project.

## Bethesda / Fallout
Bethesda/Fallout assets remain separate from Team FOLON assets. Permission for one set of assets is not assumed to cover another.
