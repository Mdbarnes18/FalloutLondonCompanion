  <strong>Native SwiftUI iPhone/iPad companion for Fallout: London.</strong>

- iOS/iPadOS 18+
- iPhone + iPad
- Portrait + landscape
- ATTA-Boy shell and CRT presentation
- Live Pip-Boy protocol integration under verified implementation
- GitHub Actions macOS IPA build for SideStore testing

## Project

Branches: `main` is stable; `develop` is active development.

**WITH THANKS TO TEAM FOLON**

Fallout: London is a Team FOLON project. This companion is separate and does not imply endorsement or affiliation.

## Build

GitHub Actions builds the iOS application on a macOS runner and produces an unsigned IPA artifact for SideStore testing.

The current implementation is under active development; feature completion and live-device verification are still in progress.
